# Plantilla — registro de cambio

Copiar esta estructura como nueva entrada en `docs/seguimiento/cambios.md`; reemplazar campos sin dejar marcadores como hechos. La numeración siguiente se obtiene del historial real.

```text
CAM-NNN — Título concreto
Fecha y zona horaria:
Solicitud o problema de origen:
Especificación, requisitos, criterios CA y tareas relacionados:
Motivo del cambio:
Alcance y comportamiento resultante:
Archivos y documentos propietarios afectados:
Decisiones/ADR relacionadas o motivo por el que no requiere ADR:
Validación ejecutada: comando, resultado y evidencia:
Validación no ejecutada y causa:
Limitaciones, riesgos y pendientes con ID:
Estado real al cerrar:
Siguiente acción concreta:
Commit o PR: solo si existe y está comprobado.
```

No incluir secretos ni transcripciones de razonamiento interno. Un resultado planeado no se registra como validación ejecutada.
