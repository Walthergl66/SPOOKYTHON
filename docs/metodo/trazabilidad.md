## Cadena de ejemplo

`PRD-05 → SPEC-004 → CA-004-03 → P4B-02 → T-14 → CAM-037 → backend/tests/test_ordenes_juego.py`.

La evidencia CAM-037 es parcial: valida aceptación y acuse local, pero aún no demuestra deadline, cierre atómico compartido ni consumo por el resolutor. Para la intervención metodológica: `TRD-13 → SPEC-006 → M0-01..04 → T-20/T-21 → CAM-004 → reporte documental`.

`python3 backend/scripts/check_sdd.py` comprueba que todos los requisitos tengan SPEC, referencias a tareas/pruebas existan, criterios usen pruebas declaradas, esta matriz coincida con metadatos y una SPEC verificada tenga CAM/evidencia. No demuestra cobertura ejecutada o semántica del requisito. Si cambia un ID, actualizar sus referencias conservando la historia de sustitución.
