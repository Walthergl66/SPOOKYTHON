# Plantilla — plan proporcional de cambio

Usar dentro de una SPEC o tarea existente; no crear un segundo roadmap. Para un cambio pequeño basta una lista breve vinculada a la especificación pertinente.

```text
Especificación y solicitud que autoriza el alcance:
Requisitos y criterios CA afectados:
Estado real antes del cambio:
Pasos pequeños, en orden, con IDs existentes o nuevos registrados en el plan:
Dependencias y módulos propietarios:
Pruebas T y comandos realmente disponibles:
Qué se considera terminado y evidencia que se guardará:
Riesgos, reversión y preguntas esenciales:
Documentos, ADR y CAM que deben actualizarse:
Siguiente acción si se interrumpe:
```

No marcar todos los pasos completados por crear este texto. Flujo completo: [SDD](../SDD.md); registro al cerrar: [plantilla de cambio](cambio.md).
