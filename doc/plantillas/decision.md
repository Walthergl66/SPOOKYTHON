# Plantilla — decisión duradera (ADR)

Crear archivo numerado bajo `doc/decisiones/` e incorporarlo a su índice. No editar esta plantilla para registrar una decisión específica.

```text
ADR-NNN — Título
Fecha:
Estado: propuesta / aceptada para diseño / implementada / sustituida
Origen: solicitud del usuario, requisito o problema observado
Contexto y restricciones:
Decisión:
Alternativas consideradas y motivo de selección:
Consecuencias, límites y costos:
Supuestos y pendientes relacionados:
Documentos y módulos propietarios afectados:
Evidencia de implementación/verificación, si existe:
Sustituye / sustituida por, si aplica:
```

Una decisión del diseño puede estar aceptada sin que el código exista. No convertir preguntas pendientes en requisitos oficiales mediante este formato.
